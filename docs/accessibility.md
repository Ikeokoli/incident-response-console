# Accessibility contract

The incident console treats accessibility as behavior rather than presentation.

- Every form control has a visible label.
- Incident rows use a semantic table and stable row headers.
- Severity and status include text instead of communicating through color alone.
- The details drawer receives focus, closes with Escape, and returns focus to its invoker.
- Loading, refresh, result-count, error, and save states are announced as text.
- Motion respects the operating system's reduced-motion preference.
- A skip link moves keyboard focus directly to the workspace.
