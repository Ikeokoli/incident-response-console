# Incident Response Console

Incident Response Console is a private React application for triaging operational incidents without depending on external services or credentials.

The project is intentionally developed as a realistic product repository: behavior is covered by self-contained tests, accessibility is part of the interaction contract, and changes are delivered as focused increments.

## Product goals

- Help responders find and prioritize active incidents.
- Preserve working context while results, filters, and incident details change.
- Keep keyboard and screen-reader workflows first-class.
- Remain fully runnable with local fixture data.
